# Loyiha tavsifi

**Mavzu:** Universitet yotoqxonasini boshqarish va talabalar farovonligini ta’minlash tizimi  

**Universitet:** Andijon Davlat Universiteti  

**Maqsad:** Yotoqxona faoliyatini raqamlashtirish, talabalar va ma’muriyat o‘rtasidagi muloqotni yaxshilash, qog‘oz ishlarini kamaytirish.

## Muammo

Hozirgi vaqtda ko‘pgina universitet yotoqxonalarida ma’lumotlar qog‘ozda yoki Excel da yuritiladi. Bu quyidagi muammolarga olib keladi:

- Xonalar bandligi haqida aniq ma’lumot yo‘qligi
- Talabalarni joylashtirish jarayonining sekinligi
- Nosozliklar (suv, elektr, mebel) haqida tezkor xabar berish imkoniyati yo‘qligi
- Hisobotlar tayyorlashda vaqt yo‘qotilishi

## Yechim

Veb-asosidagi **Yotoqxona Boshqaruv Tizimi** yaratildi. Tizim quyidagi imkoniyatlarni beradi:

1. **Talabalarni boshqarish** — yangi talaba qo‘shish, tahrirlash, o‘chirish, qidirish
2. **Xonalar boshqaruvi** — xona raqami, qavat, bo‘sh o‘rinlar
3. **Yotoqxona (Hall) ma’lumotlari**
4. **Xodimlar va yotoqxona mudiri**
5. **Ovqatlanish buyurtmalari**
6. **Muammolarni qayd etish** (buzilgan fan, chiroq va h.k.)

## Texnik yechim

- **Backend:** PHP
- **Database:** MySQL
- **Frontend:** HTML, CSS, JavaScript, Bootstrap
- **Server:** Apache (XAMPP / OpenServer)

## Natija

Tizim yordamida:

- Ma’muriyat tezkor hisobot oladi
- Talabalar o‘z ma’lumotlarini ko‘rishi mumkin
- Xonalar bandligi real vaqtda kuzatiladi
- Nosozliklar tezroq bartaraf etiladi

## Xulosa

Loyiha Andijon Davlat Universiteti yotoqxonalarida qo‘llanilishi mumkin. Kelajakda mobil ilova va to‘lov integratsiyasi qo‘shish mumkin.
